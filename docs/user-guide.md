# คู่มือการใช้งานระบบ Service Efficiency System (SES)

คู่มือฉบับนี้จัดทำขึ้นสำหรับผู้ใช้งานทุกระดับ เพื่อเป็นแนวทางปฏิบัติการบันทึกขั้นตอนการทำงานและจับเวลาประสิทธิภาพการให้บริการ (Service Efficiency) ในร้านค้าปลีก

---

## 1. ภาพรวมและกฎสำคัญของระบบ (System Overview & Core Rules)

ระบบ **Service Efficiency System (SES)** เป็นระบบ Web Application ที่พัฒนาขึ้นเพื่อบันทึกข้อมูลการปฏิบัติงานจริงและจัดเก็บเวลา (Timestamps) ในแต่ละช่วงของกระบวนการบริการลูกค้า (Customer Service Workflow) โดยนำข้อมูลดิบไปใช้ในการวิเคราะห์ประสิทธิภาพการทำงานและ KPI ต่อไป

### กฎสำคัญและข้อจำกัดของระบบ (Core Rules & Constraints)
1. **Server Time เป็นเกณฑ์มาตรฐานเดียว (Source of Truth):** เวลาในทุกขั้นตอน (Timestamps) ถูกบันทึกจากเวลาของ Server โดยตรง ไม่อนุญาตให้ผู้ใช้หรือหน้าจอ Client ระบุหรือแก้ไขเวลาย้อนหลัง
2. **ความถูกต้องของข้อมูลหลังการยืนยัน (Data Integrity & Re-confirmation):** เมื่อพนักงานยืนยันข้อมูลการซื้อแล้ว ข้อมูลจะถูกส่งต่อไปยังแผนกคลังสินค้า หากคลังสินค้าพบสินค้าครบ ข้อมูลจะถูกล็อกถาวร แต่หากเกิดกรณีสินค้าไม่พบ (Not Found) ระบบจะเปิดโอกาสให้ Staff เจรจากับลูกค้าและยืนยันข้อมูลใหม่อีกครั้ง (Re-confirmation)
3. **การระบุตัวตน (Trusted Authentication):** ทุกคำสั่งและการบันทึก Action จะยึดจากบัญชีผู้ใช้ (Staff ID) ที่ Login อยู่จริงในระบบ
4. **ความปลอดภัยของ Session:** 
   - ระบบจะหมดอายุอัตโนมัติหากไม่มีการใช้งานต่อเนื่องเกิน **8 ชั่วโมง**
   - การ Login ครั้งแรกด้วยรหัสผ่านชั่วคราว ระบบจะบังคับให้เปลี่ยนรหัสผ่านทันทีก่อนเข้าใช้งาน
5. **การทำงานร่วมกับระบบแคชเชียร์ภายนอก (FileMaker):** ระบบ SES ไม่ได้เชื่อมต่อ API กับโปรแกรม FileMaker โดยตรง พนักงานแคชเชียร์จะต้องเปิดบิลและคีย์ข้อมูลใน FileMaker ควบคู่ไปกับการกดบันทึกขั้นตอนในระบบ SES

## 2. คู่มือสำหรับพนักงานขายหน้าร้าน (Staff / DEMO)

บทบาท **STAFF** มีหน้าที่รับลูกค้า ให้บริการสาธิต/แนะนำสินค้า (DEMO) บันทึกผลการตัดสินใจ คีย์ข้อมูลรายการสินค้าที่ลูกค้าต้องการซื้อ และเจรจาหาทางออกเมื่อสินค้าในคลังไม่ครบ

```text
[ลูกค้า Walk-in] ──> [เริ่ม DEMO] ──> [จบ DEMO] ──> [บันทึกผลการตัดสินใจ]
                                                          ├── NOT BUY (จบงาน)
                                                          └── BUY ──> [ระบุเบอร์โทร] ──> [เลือกสินค้า/อุปกรณ์] ──> [ยืนยันรายการ]
                                                                                                                   │
                                                                                                                   ▼
                                                                 [รับงานส่งกลับจาก Stock] <── (กรณีไม่พบสินค้าในคลัง)
                                                                            │
                                                                            ├── ทางเลือก 1: เปลี่ยนรุ่น/สีใหม่ (ส่ง Stock หาเพิ่ม)
                                                                            ├── ทางเลือก 2: ตัดรายการที่ไม่มีออก (ส่ง Cashier ต่อ)
                                                                            └── ทางเลือก 3: ลูกค้ายกเลิกทั้งหมด (Cancel Session)
```

### ขั้นตอนการปฏิบัติงานทีละขั้นตอน

#### ขั้นตอนที่ 1: รับลูกค้าและสร้าง Session (Customer Walk-in)
1. เมื่อมีลูกค้าเดินเข้ามาในร้าน ให้กดปุ่ม **"รับลูกค้า (Walk-in)"** เพื่อสร้าง Customer Session ใหม่
   - *หมายเหตุ:* ระบบจะบันทึกเวลา `customer_walk_in_at` โดยอัตโนมัติ

#### ขั้นตอนที่ 2: เริ่มและจบการสาธิตสินค้า (DEMO)
1. เมื่อเริ่มนำเสนอหรือพูดคุยแนะนำสินค้า ให้กดปุ่ม **"เริ่ม DEMO"**
   - *ข้อกำหนด:* พนักงาน 1 ท่านสามารถเปิด Session เพื่อทำ DEMO ลูกค้าได้ครั้งละ **1 คนเท่านั้น**
   - ระบบบันทึกเวลา `demo_start_at`
2. เมื่อพูดคุยนำเสนอสินค้าเสร็จสิ้น ให้กดปุ่ม **"จบ DEMO"**
   - ระบบบันทึกเวลา `demo_end_at`

#### ขั้นตอนที่ 3: บันทึกผลการตัดสินใจของลูกค้า (Customer Decision)
ระบบจะให้เลือกผลการตัดสินใจ 2 รูปแบบ:

* **กรณีที่ 1: ลูกค้าไม่ซื้อ (NOT BUY)**
  1. เลือกตัวเลือก **"NOT BUY"**
  2. เลือกเหตุผลที่ไม่ซื้อจาก 6 ตัวเลือกที่กำหนด:
     - `ราคา`
     - `ยังไม่ตัดสินใจ`
     - `เปลี่ยนใจ`
     - `สินค้าไม่ตรงความต้องการ`
     - `ต้องการสอบถามราคาหรือรายละเอียดเฉยๆ`
     - `อื่น ๆ` *(หากเลือกข้อนี้ จะต้องระบุรายละเอียดเพิ่มเติม)*
  3. กดยืนยันเพื่อปิด Session ทันที (สถานะ `CLOSED`)

* **กรณีที่ 2: ลูกค้าตกลงซื้อ (BUY)**
  1. เลือกตัวเลือก **"BUY"** (ระบบบันทึกเวลา `decision_at`)
  2. **ระบุหมายเลขโทรศัพท์ลูกค้า:** สอบถามและกรอกเบอร์โทรศัพท์ลูกค้าจำนวน **10 หลัก (0-9)** ให้ถูกต้องครบถ้วน *(จำเป็นต้องกรอกให้ผ่าน จึงจะสามารถเลือกสินค้าได้)*
  3. ระบบบันทึกเวลาเริ่มเลือกสินค้า `product_selection_start_at`

#### ขั้นตอนที่ 4: เลือกรายการสินค้าและเงื่อนไขการซื้อ (Product Selection)
1. **สินค้าหลัก (Main Product):** เลือกหมวดหมู่ (iPhone, iPad, Mac, Watch, Accessories) -> รุ่น (Model) -> รหัสสินค้า (SKU)
   - *หมายเหตุ:* สามารถเลือกได้เฉพาะรายการสินค้าที่สาขามีสต็อกคงเหลืออยู่เท่านั้น (`stock > 0`) สินค้าที่หมดจะแสดงป้าย "สินค้าหมด" และไม่สามารถเลือกได้
2. **อุปกรณ์เสริม (Accessories):** *(ถ้ามี)*
   - เลือกรายการอุปกรณ์เสริม และระบุจำนวนชิ้น (เริ่มต้นที่ 1 ชิ้น, ต้องเป็นจำนวนเต็มบวก)
3. **ส่วนลด/โปรโมชั่น On-top (Ontop):** *(ถ้ามี)* เลือกผู้ให้บริการ (AIS, True, CATH, KTS)
4. **การสะสมคะแนน (Points) / การตัดคะแนน (Burn Point):** *(ถ้ามี)* เลือกประเภทบัตร (MCard, The 1, UJOY)
5. **วิธีการชำระเงิน (Payment):** เลือกวิธีการชำระเงินที่ลูกค้าต้องการ (Cash, Transfer, Credit Card, ผ่อนชำระ ฯลฯ)

#### ขั้นตอนที่ 5: ตรวจสอบและยืนยันคำสั่งซื้อ (Confirmation)
1. เข้าสู่หน้าจอ **สรุปรายการ (Confirmation Screen)** ตรวจสอบความถูกต้องของสินค้าและเงื่อนไขทั้งหมดต่อหน้าลูกค้า
2. หากต้องการแก้ไข ให้กดย้อนกลับไปแก้ไขข้อมูลก่อนกดยืนยัน
3. เมื่อถูกต้องครบถ้วน ให้กดปุ่ม **"ยืนยันและส่งคำขอสินค้า (Confirm & Request Stock)"**
   - ระบบจะบันทึกเวลา `product_selection_confirmed_at` พร้อมส่งงานต่อไปยังแผนก Stock (รอบค้นหา `search_cycle_count` = 1)

#### ขั้นตอนที่ 6: การจัดการกรณี Stock แจ้งสินค้าไม่พบและส่งกลับ (Handling Stock Return to Staff)
หากแผนก Stock ค้นหาแล้วพบว่าสินค้าบางชิ้นหรือสินค้าหลักไม่มีในคลัง งานจะถูกส่งกลับมาที่หน้าจอ Staff:
1. กดปุ่ม **"เริ่มเจรจากับลูกค้า (START_CONSULT)"**
   - ระบบจะบันทึกเวลา `staff_consult_start_at`
2. แจ้งลูกค้าถึงสถานะสินค้าที่ไม่พบ และให้ลูกค้าเลือก 1 ใน 3 ทางออก:
   - **ทางเลือก A (เปลี่ยนสินค้าใหม่):** ลูกค้าตกลงเปลี่ยนรุ่น/สี หรือเปลี่ยนอุปกรณ์เสริมเป็นรายการอื่น -> เลือกสินค้าใหม่ที่มีสต็อก -> กดยืนยันเพื่อส่ง Stock หาเพิ่ม (ระบบบันทึก `re_confirmed_at`, ผลลัพธ์ `CHANGED_ITEM`, เพิ่มรอบค้นหา `search_cycle_count` เป็น 2)
   - **ทางเลือก B (ตัดรายการที่ไม่มีออก):** ลูกค้าขอรับเฉพาะชิ้นที่มีอยู่แล้วและไม่เอาของเพิ่ม -> กดยืนยันตัดรายการที่ขาด -> ส่งงานต่อไปยังแคชเชียร์ทันที (ระบบบันทึก `re_confirmed_at`, ผลลัพธ์ `DROPPED_ITEM`)
   - **ทางเลือก C (ลูกค้ายกเลิกคำสั่งซื้อ):** ลูกค้าไม่ต้องการสินค้าแล้ว -> กดปุ่ม "ยกเลิกคำสั่งซื้อ" (ระบบบันทึก `cancelled_at`, ผลลัพธ์ `CANCELLED` และทำการคืนสต็อกชิ้นที่หยิบได้ก่อนหน้าเข้าคลังอัตโนมัติ)

## 3. คู่มือสำหรับพนักงานคลังสินค้า (Stock)

บทบาท **STOCK** มีหน้าที่รับคำขอสินค้า ค้นหาสินค้าในคลัง จัดเตรียมเครื่อง ส่งต่องานไปยังแคชเชียร์ หรือแจ้งส่งกลับกรณีสินค้าขาด

```text
[ได้รับคำขอ] ──> [กด SEARCHING] ──> [ค้นหาสินค้าในคลัง]
                                           ├── พบสินค้าครบ ──> [กด FOUND] ──> [กด SENT_TO_CASHIER]
                                           ├── ไม่พบสินค้า/สินค้าขาด ──> [เลือกชิ้นที่ไม่พบ & กด RETURN_TO_STAFF]
                                           └── สินค้าหมดสิ้นเชิง (ไม่มีทางเลือกอื่น) ──> [กด OUT_OF_STOCK]
```

### ขั้นตอนการปฏิบัติงานทีละขั้นตอน

#### ขั้นตอนที่ 1: ตรวจสอบรายการคำขอ (View Stock Requests)
1. เปิดหน้าจอแผนก Stock ระบบจะแสดงรายการคำขอสินค้าที่มีสถานะ `STOCK_REQUESTED` ของสาขาตนเอง

#### ขั้นตอนที่ 2: เริ่มต้นค้นหาสินค้า (Searching)
1. เมื่อเริ่มเดินไปค้นหาสินค้าในคลัง ให้กดปุ่ม **"ค้นหาสินค้า (SEARCHING)"**
   - *ข้อสำคัญ:* การเปิดดูหน้าจอเฉย ๆ ยังไม่นับเป็นการเริ่มหา ต้องกดปุ่มเพื่อเริ่มจับเวลา
   - ระบบบันทึกเวลา `stock_started_at`

#### ขั้นตอนที่ 3: บันทึกผลการค้นหาสินค้า
* **กรณีที่ 1: พบสินค้าครบถ้วน (FOUND)**
  1. เมื่อหยิบสินค้าครบทุกชิ้นแล้ว ให้กดปุ่ม **"พบสินค้า (FOUND)"**
     - ระบบบันทึกเวลา `stock_found_at`
     - **ระบบจะทำการตัดสต็อกคงคลังของสาขานั้นออกตามจำนวนชิ้นที่หยิบโดยอัตโนมัติ**
  2. นำสินค้าไปส่งที่จุดรับสินค้าของแคชเชียร์ แล้วกดปุ่ม **"ส่งต่อแคชเชียร์ (SENT_TO_CASHIER)"**

* **กรณีที่ 2: ไม่พบสินค้าบางชิ้น หรือไม่พบสินค้าหลัก (RETURN_TO_STAFF - แนะนำ)**
  1. หากชิ้นใดหาไม่พบ ให้ทำเครื่องหมายเลือกรายการสินค้าที่ไม่พบ (เช่น เคสสีดำหมด หรือ ความจุ 256GB สีน้ำเงินหมด)
  2. ชิ้นที่หาเจอแล้ว (ถ้ามี) ให้เก็บแยกไว้ข้างกล่อง
  3. กดปุ่ม **"ส่งกลับ Staff เพื่อถามลูกค้า (RETURN_TO_STAFF)"**
     - ระบบบันทึกเวลา `stock_not_found_at`
     - ระบบจะปรับสต็อกของชิ้นที่ไม่พบเป็น **0 ทันที** และส่ง Alert แจ้งเตือนไปยัง Branch Manager
     - สินค้าชิ้นที่หาเจอแล้วจะยังคงถูกล็อคไว้ ไม่ถูกนำไปขายให้คิวอื่น
     - งานจะเด้งกลับไปที่หน้าจอพนักงานขาย (Staff) เพื่อสอบถามลูกค้าทันที

* **กรณีที่ 3: สินค้าหมดสิ้นเชิงและต้องการปิดงาน (OUT_OF_STOCK)**
  1. ใช้เฉพาะกรณีที่ไม่สามารถเจรจาเปลี่ยนสินค้าใด ๆ ได้เลย
  2. กดปุ่ม **"สินค้าหมด (OUT_OF_STOCK)"** -> Session จะสิ้นสุดลงทันที (สถานะ `CLOSED`)

## 4. คู่มือสำหรับพนักงานแคชเชียร์ (Cashier)

บทบาท **CASHIER** มีหน้าที่รับมอบสินค้าจาก Stock ทำการสแกนตรวจสอบ เปิดบิลรับชำระเงินในโปรแกรมหลัก (FileMaker) และส่งมอบสินค้าให้ลูกค้า

```text
[รับสินค้าจาก Stock] ──> [กด รับสินค้า] ──> [กด Scan ตรวจสอบ] ──> [กด เปิดบิล / บันทึก FileMaker] ──> [กด COMPLETED]
```

### ขั้นตอนการปฏิบัติงานทีละขั้นตอน

#### ขั้นตอนที่ 1: รับมอบสินค้า (Cashier Received)
1. เมื่อพนักงาน Stock นำสินค้ามาวางที่จุดแคชเชียร์ ให้ตรวจสอบหน้าจอที่มีสถานะ `SENT_TO_CASHIER`
2. กดปุ่ม **"รับสินค้า (CASHIER_RECEIVED)"**
   - ระบบบันทึกเวลา `cashier_received_at`

#### ขั้นตอนที่ 2: สแกนบาร์โค้ด / Serial Number (Cashier Scan)
1. ตรวจสอบความถูกต้องของกล่องสินค้าและสแกนบาร์โค้ด
2. กดปุ่ม **"สแกนสินค้า (CASHIER_SCAN)"**
   - ระบบบันทึกเวลา `cashier_scan_at`

#### ขั้นตอนที่ 3: เปิดบิลในระบบหลักและรับชำระเงิน (Bill Opened)
1. ดำเนินการเปิดใบเสร็จรับเงิน/ใบกำกับภาษีในระบบ **FileMaker** ตามขั้นตอนปกติ
2. กดปุ่ม **"เปิดบิล (BILL_OPENED)"** ในระบบ SES
   - ระบบบันทึกเวลา `bill_opened_at`
3. ดำเนินการรับชำระเงินและออกเอกสารให้ลูกค้าใน FileMaker

#### ขั้นตอนที่ 4: ส่งมอบสินค้าและเสร็จสิ้นกระบวนการ (Completed)
1. ส่งมอบสินค้าและใบเสร็จให้แก่ลูกค้า
2. กดปุ่ม **"เสร็จสิ้น (COMPLETED)"** ในระบบ SES เพื่อปิดงานอย่างสมบูรณ์

## 5. คู่มือสำหรับผู้จัดการสาขา (Branch Manager)

บทบาท **MANAGER** ได้รับสิทธิ์ในการบริหารจัดการข้อมูลภายในสาขาของตนเอง ดูรายงานย้อนหลัง และตรวจสอบกรณีสินค้าผิดปกติ

### สิทธิ์และความรับผิดชอบ
1. **การจัดการพนักงานในสาขา (Staff Management):**
   - สร้างบัญชีผู้ใช้ใหม่สำหรับสาขาตนเอง (กำหนด Staff ID, ชื่อ, รหัสผ่านชั่วคราว)
   - กำหนดบทบาทพนักงาน (STAFF, STOCK, CASHIER)
   - ระงับการใช้งานบัญชีพนักงาน (Deactivate)
2. **การจัดการเปิด/ปิดการขายสินค้าในสาขา (Toggle Product Active):**
   - สามารถเปิด (`Active = true`) หรือปิด (`Active = false`) การขายของแต่ละ SKU ในสาขาตนเองได้
3. **การตรวจสอบกรณีสินค้าหมดและการส่งกลับ (Out-of-Stock Investigation):**
   - เมื่อฝ่าย Stock กด `RETURN_TO_STAFF` หรือ `OUT_OF_STOCK` Manager จะได้รับการแจ้งเตือน เพื่อเข้าตรวจนับสต็อกจริงในคลังว่าสินค้าสูญหาย (Loss) หรือวางผิดที่ (Misplaced)
4. **การดูรายงานและ Export ข้อมูล:**
   - สามารถดูประวัติ Session ย้อนหลัง ดูสถิติการเจรจาเปลี่ยนสินค้า และ Export ข้อมูลรายงานประสิทธิภาพเฉพาะสาขาของตนเองได้

## 6. คู่มือสำหรับผู้ดูแลระบบระดับสูง (Global Admin)

บทบาท **ADMIN** มีสิทธิ์สูงสุดระดับองค์กร ครอบคลุมทุกสาขาในระบบ

### สิทธิ์และความรับผิดชอบ
1. **การจัดการสาขา (Branch Management):** เพิ่ม แก้ไข และปิดการใช้งานสาขาทั่วประเทศ
2. **การจัดการข้อมูลสินค้าหลัก (Product Master Data):** สร้าง/แก้ไข Category, Product, Model และ SKU ในระบบส่วนกลาง
3. **การจัดสรรสต็อกสาขา (Branch Inventory Management):** กำหนดจำนวนสต็อกตั้งต้น (`Stock Quantity`) ของแต่ละ SKU ให้แต่ละสาขา
4. **การบริหารจัดการผู้ใช้ระดับระบบ (User & Permission Management):** จัดการบัญชีพนักงาน รีเซ็ตรหัสผ่านให้พนักงานทุกระดับ
5. **การวิเคราะห์ข้อมูลระดับองค์กร (System Efficiency Dashboard):** เข้าถึง Dashboard และ Export ข้อมูลดิบทั้งหมดเพื่อการวิเคราะห์

## 7. กฎการตัดและคืนสต็อกอัตโนมัติ (Stock Deduction & Restoration Matrix)

| เหตุการณ์ที่เกิดขึ้น | ผลต่อสต็อกในระบบ | คำอธิบาย |
| :--- | :---: | :--- |
| ฝ่าย Stock กด **FOUND** | **-1** | ระบบตัดสต็อก 1 ชิ้นทันทีที่ยืนยันว่าพบสินค้า |
| ฝ่าย Stock กด **RETURN_TO_STAFF** (ชิ้นที่ไม่พบ) | **ปรับเป็น 0** | ปรับสต็อกชิ้นที่ไม่พบเป็น 0 ทันที + แจ้งเตือน Manager (ชิ้นที่เจอแล้วคงถูกตัด/จองไว้) |
| ลูกค้ายกเลิก **หลังจากกด FOUND หรือระหว่างเจรจา** | **+1** | ระบบจะคืนสต็อกเฉพาะชิ้นที่เคยหยิบได้แล้วกลับเข้าคลังสาขาโดยอัตโนมัติ |
| ลูกค้ายกเลิก **ก่อนที่ Stock จะกด FOUND** | **ไม่เปลี่ยนแปลง** | ยังไม่มีการตัดสต็อก จึงไม่มีการคืนสต็อก |

## 8. แนวทางการนำข้อมูลไปวิเคราะห์ประสิทธิภาพ (Efficiency & KPI Analytics Guide)

ข้อมูล Timestamps และข้อมูลดิบที่ระบบบันทึก สามารถนำไปคำนวณ KPI เชิงลึกได้ดังนี้:

```text
                                         [TIMESTAMPS OVERVIEW]
customer_walk_in_at ──> demo_start_at ──> demo_end_at ──> decision_at ──> product_selection_start_at ──> product_selection_confirmed_at
                                                                                                                   │
                                                                                                                   ▼
completed / cancelled <── bill_opened_at <── cashier_scan_at <── cashier_received_at <── stock_found_at <── stock_started_at
           ▲
           │ (Loop กรณีสินค้าไม่พบ)
           └── re_confirmed_at <── staff_consult_start_at <── stock_not_found_at
```

### 1. ดัชนีวัดความแม่นยำของสต็อก (Stock Accuracy Rate)
$$\text{Stock Accuracy Rate (\%)} = \left( 1 - \frac{\text{จำนวน Session ที่เกิด Not Found}}{\text{จำนวน Session ที่เบิกสินค้าทั้งหมด}} \right) \times 100$$

### 2. เวลาที่สูญเสียในการค้นหาสินค้าที่ไม่มีจริง (Search Loss Time)
$$\text{Search Loss Time} = \text{stock\_not\_found\_at} - \text{stock\_started\_at}$$
*เป้าหมาย:* ลดเวลาเฉลี่ยที่พนักงานคลังต้องเสียไปกับการเดินหาสินค้าที่ระบบระบุว่ามี แต่หน้างานไม่มีจริง

### 3. ระยะเวลาที่ใช้ในการเจรจาและรักษาการขาย (Customer Consultation Duration)
$$\text{Consultation Duration} = \text{re\_confirmed\_at} - \text{staff\_consult\_start\_at}$$
*เป้าหมาย:* วิเคราะห์ทักษะของพนักงานขายในการนำเสนอตัวเลือกใหม่เพื่อรักษาลูกค้าได้อย่างรวดเร็ว

### 4. อัตราการรักษาการขายเมื่อสินค้าขาด (Sales Retention / Save Rate)
$$\text{Retention Rate (\%)} = \left( \frac{\text{Session ที่จบด้วย CHANGED\_ITEM} + \text{DROPPED\_ITEM}}{\text{Session ที่เกิด Not Found ทั้งหมด}} \right) \times 100$$
*เป้าหมาย:* วัดความสำเร็จในการเปลี่ยนวิกฤตสินค้าหมดให้เป็นยอดขายทางเลือกแทนที่จะเสียลูกค้าไป

## 9. สรุปรายการคำศัพท์และสถานะในระบบ (System Glossary)

| รหัสสถานะ | ความหมาย | บทบาทผู้รับผิดชอบ |
| :--- | :--- | :--- |
| `WALK_IN` | ลูกค้าเดินเข้าสู่ร้านค้า และเริ่มสร้าง Session | Staff |
| `DEMO` | พนักงานกำลังสาธิต/แนะนำสินค้าให้ลูกค้า | Staff |
| `DECISION` | จบการสาธิต อยู่ระหว่างการตัดสินใจซื้อ/ไม่ซื้อ | Staff |
| `PRODUCT_SELECTION` | ลูกค้าเลือกซื้อ กำลังระบุเบอร์โทรและเลือกสินค้า | Staff |
| `CONFIRMATION` | พนักงานและลูกค้าตรวจสอบความถูกต้องของรายการ | Staff |
| `STOCK_REQUESTED` | รายการสั่งซื้อยืนยันแล้ว รอพนักงานคลังหยิบสินค้า | Staff -> Stock |
| `SEARCHING` | พนักงานคลังกำลังเดินค้นหาสินค้าในสต็อก | Stock |
| `FOUND` | พนักงานคลังพบสินค้า และตัดสต็อกตามจำนวนที่หยิบ | Stock |
| `RETURNED_TO_STAFF` | คลังไม่พบสินค้า ส่งเรื่องกลับมาให้ Staff เจรจาลูกค้า | Stock -> Staff |
| `STAFF_CONSULTING` | Staff กำลังพูดคุยเสนอทางเลือกใหม่ให้ลูกค้า | Staff |
| `SENT_TO_CASHIER` | พนักงานคลังนำสินค้าไปส่งที่จุดแคชเชียร์ | Stock |
| `CASHIER_RECEIVED` | แคชเชียร์รับสินค้าเรียบร้อยแล้ว | Cashier |
| `CASHIER_SCAN` | แคชเชียร์สแกนบาร์โค้ดตรวจสอบสินค้า | Cashier |
| `BILL_OPENED` | แคชเชียร์เปิดบิลในระบบ FileMaker | Cashier |
| `COMPLETED` | ส่งมอบสินค้าและเสร็จสิ้นกระบวนการบริการ | Cashier |
| `OUT_OF_STOCK` | สินค้าในคลังหมด จบ Session ทันที | Stock |
| `CUSTOMER_CANCELLED` | ลูกค้ายกเลิกการรับบริการ จบ Session ทันที | Staff / Stock / Cashier |
| `CLOSED` | ปิด Session เรียบร้อย (เช่น กรณี NOT BUY หรือ OUT_OF_STOCK) | System |
