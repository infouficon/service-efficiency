## Context
What forces this decision? Cite the code (`file:line`) and the business rule (D##). Say what happens today.

## Decision
The choice, in one or two sentences, then the concrete shape (schema change, API contract, who
checks what). Be specific enough that a stranger could implement it without asking.

- **Option B:** why not.

## Consequences
